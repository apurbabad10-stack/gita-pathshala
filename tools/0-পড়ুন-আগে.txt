গীতা পাঠশালা — বই থেকে পূর্ণ টেক্সট তোলার কিট (Route B)
=======================================================

আপনি পাচ্ছেন:
  gita-pages-part1/2/3.zip   বইয়ের ১০৪২টি একক পাতার ছবি (p0001a.jpg … p0521b.jpg)
  1-OCR-Code.gs              Google Drive-এ বাংলা OCR চালানোর স্ক্রিপ্ট
  2-Gita-Text-Studio.html    শ্লোক আলাদা করা, প্রুফ দেখা ও gita-data.json বানানোর টুল

সব কাজ কম্পিউটারে (Chrome ব্রাউজারে) করুন।

ধাপ ১ — zip ফাইল Google Drive-এ রাখুন (≈১০ মিনিট)
  1. Google Drive-এ "Gita Pages" নামে ফোল্ডার খুলুন (নাম হুবহু এটাই)।
  2. gita-zip-1.zip থেকে gita-zip-8.zip পর্যন্ত ৮টি ফাইল ওই ফোল্ডারে আপলোড করুন।
     ⚠ unzip করবেন না। স্ক্রিপ্ট নিজেই Drive-এর ভেতরে unzip করবে।
  (আগের gita-pages-part1/2/3.zip আর লাগবে না।)

ধাপ ২ — OCR চালান (নিজে নিজে চলে, ≈১–২ ঘণ্টা)
  1. script.google.com → New project
  2. 1-OCR-Code.gs খুলে সব লেখা কপি করে পেস্ট করুন।
  3. বাম দিকে Services (+) → Drive API → Version v3 → Add
  4. উপরে ফাংশন "start" বেছে Run চাপুন, অনুমতি দিন।
  5. প্রথমে স্ক্রিপ্ট zip খুলে ১০৪২টি পাতা তৈরি করে, তারপর OCR শুরু করে। ৫ মিনিট করে কাজ করে,
     নিজেই আবার চালু হয়। অগ্রগতি দেখতে "status" চালান।
     দৈনিক সময়সীমায় থেমে গেলে পরদিন "runOcr" চালান ("start" নয়)।
  6. শেষ হলে "Gita Pages" ফোল্ডারে gita-ocr.txt তৈরি হবে। ডাউনলোড করুন।

দ্রুত বেটা পথ (প্রুফ দেখা অ্যাপের ভেতরে, ৬ জনে মিলে)
  ক. ধাপ ২-এর পর Studio-তে gita-ocr.txt খুলে সঙ্গে সঙ্গে "gita-data.json তৈরি" চাপুন।
     উপরের যাচাই টেবিলে কোনো অধ্যায়ে "নেই" থাকলে শুধু সেগুলো আগে ঠিক করে নিন।
  খ. gita-data.json GitHub-এর www ফোল্ডারে আপলোড করুন (ধাপ ৪)। নতুন APK-তে পূর্ণ টেক্সট চলে আসবে।
  গ. ৫ জন টেস্টারকে APK, একটি আমন্ত্রণ কোড, বইয়ের PDF আর ৩–৪টি অধ্যায় ভাগ করে দিন।
     প্রস্তাবিত ভাগ (প্রায় সমান পাতা): ১ম জন ১–২, ২য় ৩–৫, ৩য় ৬–৯, ৪র্থ ১০–১২, ৫ম ১৩–১৬, আপনি ১৭–১৮।
  ঘ. টেস্টার অ্যাপে: পুরস্কার পাতা → প্রোফাইল → "প্রুফ দেখার মোড" চালু → গ্রন্থ → "✎ প্রুফ দেখা"
     → নিজের অধ্যায় বেছে নেন → প্রতিটি শ্লোক বইয়ের সঙ্গে মিলিয়ে "✎ সংশোধন" বা "✓ বইয়ের সঙ্গে মিলেছে"।
  ঙ. দিনের শেষে টেস্টার "সংশোধন কপি করুন" চেপে WhatsApp-এ আপনাকে পেস্ট করে পাঠান।
  চ. আপনি Studio-তে প্রজেক্ট খুলে "টেস্টারদের সংশোধন যোগ" → সবার মেসেজ পেস্ট → "যোগ করুন"
     → "gita-data.json তৈরি" → GitHub-এ আপলোড। সবার অ্যাপে সংশোধিত টেক্সট চলে যাবে।
  ⚠ মূল শ্লোক কখনো "সাজিয়ে" লিখবেন না; শুধু বইয়ের সঙ্গে মিলিয়ে OCR-এর ভুল ঠিক করুন।

ধাপ ৩ — শ্লোক আলাদা করা ও প্রুফ দেখা (Studio-তে, বেটা পথ না নিলে)
  1. 2-Gita-Text-Studio.html ফাইলটি Chrome-এ খুলুন।
  2. "OCR টেক্সট খুলুন" → gita-ocr.txt
  3. "পাতার ছবির ফোল্ডার" → unzip করা ছবির ফোল্ডার। এখন প্রতিটি শ্লোকের পাশে বইয়ের আসল পাতা দেখাবে।
  4. উপরের যাচাই টেবিলে প্রতিটি অধ্যায়ে কতগুলো শ্লোক পাওয়া গেছে তা দেখুন।
  5. প্রতিটি শ্লোক খুলে মূল শ্লোক বইয়ের সঙ্গে অক্ষরে অক্ষরে মিলিয়ে ঠিক করুন, তারপর "যাচাই হয়েছে" টিক দিন।
     শব্দার্থ, গীতার গান, অনুবাদ, তাৎপর্যও একবার দেখে নিন।
  6. মাঝে মাঝে "প্রজেক্ট সেভ" করুন (gita-studio-project.json)। পরে "প্রজেক্ট খুলুন" দিয়ে আবার শুরু করা যায়।
  7. কাজ এগোলে যেকোনো সময় "gita-data.json তৈরি" চাপুন।

ধাপ ৪ — অ্যাপে পূর্ণ গীতা যোগ করুন
  1. github.com/apurbabad10-stack/gita-pathshala → www ফোল্ডার খুলুন।
  2. Add file → Upload files → gita-data.json → Commit changes
  3. ৩–৪ মিনিটে নতুন APK তৈরি হবে (Releases-এ)। ইনস্টল করলেই ১২+ বয়সীরা পূর্ণ গীতা পড়তে পারবে।
  প্রতিবার প্রুফ এগোলে নতুন gita-data.json আপলোড করলেই অ্যাপ আপডেট হবে।

জেনে রাখুন
  - স্ক্যানের মান মাঝারি (প্রতি ইঞ্চিতে ≈৮৪ বিন্দু), তাই OCR-এ যুক্তাক্ষর ও সংস্কৃত শব্দে ভুল থাকবে।
    মূল শ্লোক প্রতিটি নিজে মিলিয়ে নেওয়া জরুরি; এক অধ্যায়ে ১–৩ ঘণ্টা লাগতে পারে।
  - কাজ ভাগ করে নিতে পারেন: একেকজন একেকটি অধ্যায় প্রুফ করে প্রজেক্ট ফাইল পাঠাবেন।
  - এই সংস্করণে ১৩শ অধ্যায়ে ৩৫টি শ্লোক (মোট ৭০১)। স্টুডিও সেভাবেই গোনে।
  - বইয়ের টেক্সট ও এই ফাইলগুলো শুধু অনুমোদিত কাজে ব্যবহার করুন; অ্যাপ বড় পরিসরে ছাড়ার আগে
    BBT-র লিখিত অনুমতি রাখুন।
